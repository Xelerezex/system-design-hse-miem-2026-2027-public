# HW1 V2: экспериментальные доказательства

Содержимое директории получено из архива девяти проверенных прогонов от 13.11.2026.

- `RESULTS.md` и `run-metrics.csv`: все 9 сравнений (3 варианта × 3 запуска).
- `*-explain-*.txt`, `*-pricing-sql.txt`, `*-pg-top.txt`: планы выполнения и статистика PostgreSQL (репрезентативный запуск №2, отдельно для варианта).
- `*-pprof-top.txt`: CPU-профиль, снятый во время k6.
- `*-traces-slow.txt`: результаты поиска в Tempo; сами JSON spans не приложены.
- `*-invariants.txt`: результат после k6.
- `hold_p99.png`, `pay_p99.png`: графики по трем независимым прогонам.
- `STATUS.txt`, `repository.txt`: проверки и состояние репозитория на момент сбора.
- `bench.sh`, `collect-evidence.sh`: использованные для измерений вспомогательные скрипты; имеют привязки к локальному `/tmp` и пути репозитория, **не запускайте их без проверки**.

Полный первоначальный архив всех исходных k6 JSON/логов хранится отдельно как `soldout-hw1-submission-evidence.tar.gz` (не дублируется в этой папке, потому что содержит многотысячные массивы seat ID в `setup_data`).
